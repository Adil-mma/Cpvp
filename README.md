# Cpvp

Minecraft 26.2 client-side Fabric mod.

- Press `9` to open the two-panel Crystal / Anchor GUI.
- Left-click a module to toggle its saved state.
- Right-click a module to open its settings.
- Auto Totem supports Auto and Manual modes; press `L` to toggle it.

The Crystal and Anchor entries currently have configuration screens only. Their automated combat actions are not implemented and are shown as configuration-only in the GUI.
